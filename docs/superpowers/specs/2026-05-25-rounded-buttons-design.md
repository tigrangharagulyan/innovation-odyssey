# Rounded Buttons Design
Date: 2026-05-25

## Goal
Replace all rectangular button drawables in Innovation Odyssey with rounded-corner versions (r=22 virtual units). Applies to all three button categories: default Scene2D TextButtons, Engineering Lab tile NinePatches, and MainMenuScreen ShapeRenderer-drawn buttons.

## Scope
- `OdysseyGame.buildSkin()` — new helper, updated default style, updated tile styles
- `MainMenuScreen.java` — rounded ShapeRenderer drawing for NEW GAME, SHOP, LEADERBOARD buttons
- No other files need changes; no asset files are added or removed (tile PNGs become unused dead files)

## Corner Radius
r = 22 pixels on the 64×64 Pixmap used for NinePatch generation. NinePatch margin = r + 2 = 24px.

---

## Component 1 — `makeRoundedBtn` Helper (OdysseyGame.java)

```java
private static NinePatchDrawable makeRoundedBtn(Color fill, Color border, int r) {
    int SIZE = 64;
    Pixmap pm = new Pixmap(SIZE, SIZE, Pixmap.Format.RGBA8888);
    pm.setColor(0, 0, 0, 0);
    pm.fill();
    // filled rounded rect
    pm.setColor(fill);
    fillRoundedRect(pm, 0, 0, SIZE, SIZE, r);
    // 1px border
    pm.setColor(border);
    drawRoundedRectBorder(pm, 0, 0, SIZE, SIZE, r, 1);
    Texture tex = new Texture(pm);
    pm.dispose();
    int m = r + 2;
    NinePatch np = new NinePatch(tex, m, m, m, m);
    return new NinePatchDrawable(np);
}
```

`fillRoundedRect` and `drawRoundedRectBorder` are private static Pixmap helpers.
- `fillRoundedRect`: fills four corner circles + two horizontal strips + two vertical strips.
- `drawRoundedRectBorder`: traces the border pixel-by-pixel using the rounded rect edge formula, thickness = 1-2px.

These helpers already exist in spirit inside `makeSciBtn()` — they are extracted as standalone methods.

## Component 2 — Default TextButtonStyle

The existing default style uses a 1×1 white Pixmap (`newDrawable("white", color)`). Screens tint buttons each frame via `button.setColor(OdysseyTheme.BTN_*)`, so the drawable is always white and gets tinted.

**Change:** Replace the flat white drawables with a single `makeRoundedBtn(Color.WHITE, new Color(1,1,1,0.25f), 22)` for `up`/`over`/`down` states. The disabled state uses `makeRoundedBtn(Color.WHITE, new Color(1,1,1,0.08f), 22)` (fainter border). The per-frame `setColor()` tinting flow is **unchanged** — rounding is purely cosmetic.

## Component 3 — Tile NinePatch Styles

Replace the 6 PNG-loaded NinePatches with programmatic equivalents. Color mapping:

| Skin key | Fill color | Border color |
|----------|-----------|--------------|
| `tile_locked` | `BTN_LOCKED` | `PANEL_BORDER` |
| `tile_available` | `BTN_AVAILABLE` | `PANEL_BORDER` lighter |
| `tile_buyable` | `BTN_BUYABLE` | `ACCENT_E` (#2255CC) |
| `tile_active` | `BTN_ACTIVE` | `ACCENT_E` bright |
| `tile_go` | `BTN_GO` | `ACCENT_GO` (#00FF44) |
| `tile_golocked` | `BTN_GO_LOCKED` | `PANEL_BORDER` |

Each uses `makeRoundedBtn(fill, border, 22)`. The `_dn` (pressed) variants use slightly darker fill (multiply by 0.75).

`tile_buygreen` / `tile_buygreen_dn` are generated by `makeSciBtn()` which already produces a rounded drawable — **no change needed there**.

The 6 PNG texture files in `assets/ui/` (`btn_locked.png`, `btn_available.png`, `btn_buyable.png`, `btn_active.png`, `btn_go.png`, `btn_golocked.png`) become unused. They are left in place for now and can be deleted in a cleanup pass.

## Component 4 — MainMenuScreen ShapeRenderer Buttons

Three buttons are drawn manually: NEW GAME, SHOP, LEADERBOARD.

Add a private helper:
```java
private void drawRoundedRect(ShapeRenderer sr, float x, float y, float w, float h, float r, int seg)
```
Draws a filled + outlined rounded rectangle using triangle fan (filled) and line strip (outline) approximations, consistent with how the rest of the ShapeRenderer UI works in this screen.

Replace the `sr.rect(...)` calls inside `drawNewGameButton()`, `drawShopButton()`, and the LEADERBOARD draw block with calls to `drawRoundedRect(...)` using the same bounding-box constants (`NG_X/Y/W/H`, `SH_X/W/H`, `LB_X/W/H`).

r = 14f for ShapeRenderer buttons (slightly less than NinePatch r=22 because ShapeRenderer coordinates are in the same 480×854 virtual space and these buttons are already sized proportionally).

## What Does Not Change
- All `OdysseyTheme` color constants — unchanged
- All `button.setColor()` tinting logic in every screen — unchanged
- `makeSciBtn()` — already produces a rounded result, left as-is
- `rounded_dark` / `rounded_popup` NinePatch panel drawables — unchanged
- `button_primary` / `button_secondary` / `button_disabled` PNG registrations — remain registered but still unused
